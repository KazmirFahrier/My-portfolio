// Module: System Control
module FPGA_SoC (
    input  wire clk,
    input  wire rst_n,
    output reg  led_status
);

  always @(posedge clk) begin
    if (!rst_n)
       led_status <= 1'b0;
    else
       // Toggle status output
       led_status <= ~led_status;
  end
endmodule

Thesis research | Public OpenNeuro dataset

Motor task decoding from fMRI

Developed a 3D CNN and Transformer prototype, then investigated generalization across 62 subjects using separate subject folds, nuisance controls, and nested preprocessing comparisons.

The current native smoothing confirmation reports 0.8639 balanced accuracy for independent predictions and 0.8959 for assignment using a complete run. These are different evaluation protocols. The earlier pooled prototype result does not establish generalization to unseen subjects.
